# Word-meaning source

Chapters 1, 2, 4, and 5 use the bilingual word tables at
[bhagwadgita.info](https://bhagwadgita.info/). Use the same source for new
chapters that retain the Swami Ramsukhdas Hindi verse translation. Each source
row is grouped to the reader's displayed Sanskrit token and rendered directly
below that word; this is not a verse-wide summary.

Run `node authoring/scripts/import-gita-word-meanings.cjs` to refresh the
maps, and review its alignment report before accepting generated changes. For
any source-table omission, add a compact bilingual supplement for the exact
displayed token, then rerun the chapter validator.

Chapter 3 retains its previously reviewed inline bilingual token glosses.
